# Lights Out: versión de prueba

Juego de terror multijugador para 2 a 6 jugadores: 1 tank contra hasta 5 survivors, por rondas. Es una versión en desarrollo: va a tener errores, y encontrarlos es el objetivo.

## Descargar

1. Entrá a **[Releases](../../releases/latest)**.
2. Bajá el archivo `LightsOut-...-win64.zip`.
3. Descomprimilo completo en una carpeta y abrí `LightsOut.exe`.

Windows puede mostrar "Windows protegió su PC" porque el juego no está firmado: **Más información** y después **Ejecutar de todas formas**.

Dentro del zip, `LEEME.txt` explica cómo conectarse, los controles y qué contarnos después de jugar. `CREDITOS.txt` lista los autores de los modelos, sonidos y herramientas.

## Importante

- Todos los jugadores de una partida tienen que usar **el mismo zip**. Con versiones distintas el juego rechaza la conexión.
- Solo Windows 10 u 11 de 64 bits.
- Este repositorio publica solo las versiones de prueba, no el código fuente.
